# Fonts

All five are free, open-license fonts from Google Fonts (SIL Open Font License), so they're fine to use in Canva, print and social.

| Role | Font | Get the installable version |
|---|---|---|
| Headlines | Bodoni Moda (regular and italic) | https://fonts.google.com/specimen/Bodoni+Moda |
| Labels, buttons, logo caps | Syne (use ExtraBold 800 for the logo) | https://fonts.google.com/specimen/Syne |
| Script / signature, logo "guide" | Mrs Saint Delafield | https://fonts.google.com/specimen/Mrs+Saint+Delafield |
| Body text | Instrument Sans | https://fonts.google.com/specimen/Instrument+Sans |
| Addresses and small asides | Courier Prime | https://fonts.google.com/specimen/Courier+Prime |

The `.woff2` files in this folder are the web versions the app uses. Design tools (Canva, Photoshop, Keynote) need the installable `.ttf` versions: download them from the links above. Canva already includes Bodoni Moda, Syne, Instrument Sans and Courier Prime in its font list; Mrs Saint Delafield may need searching for or uploading (uploading fonts needs Canva Pro).
