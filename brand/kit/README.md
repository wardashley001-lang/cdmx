# La Güera's Guide: brand kit

Everything you need to make something on-brand. The full rules are in `BRAND_GUIDE.pdf`.

- `logos/`: the logo in four versions, as transparent PNG (2156 px wide, for Canva and social) and vector PDF (for print).
  - `la-gueras-guide-dark-text`: on white or light pink
  - `la-gueras-guide-pink-on-dark`: on oxblood (#4A0B18) or deep wine
  - `la-gueras-guide-white`: on photos or very dark backgrounds
  - `la-gueras-guide-on-pink`: on rosa pink (#E0368C)
- `colors/`: `swatches.png` (picture of the palette), `palette.json` (names, hex codes, what each is for), `colors.css` (the app's full color file).
- `fonts/`: the five fonts and where to get the installable versions.
- `instagram/`: the two profile-picture options (1080 x 1080).
- `BRAND_GUIDE.pdf`: the 9-page guide.

## Set it up in Canva (about 10 minutes, your account)
1. Canva > **Brand** (left sidebar) > **Brand Kit** > create one named "La Güera's Guide".
2. **Logos:** upload the four PNGs from `logos/`.
3. **Colors:** add the six core colors from `colors/palette.json` first (Vino 900 #2A0710, Vino 800 #4A0B18, Rosa 500 #E0368C, Rosa 200 #F7CAD8, Leche 50 #FFF8F7, Leche 100 #FBEFF0), then the support colors if you want them.
4. **Fonts:** set Bodoni Moda for headings, Instrument Sans for body (search for them in the font list). Add Syne, Mrs Saint Delafield and Courier Prime if your plan lets you.
5. Tell me when it's done and I can check it.

Photos: run them through `brand/photo-grade/grade.py` (in the app repo) before using them, so they match the app and Instagram.
